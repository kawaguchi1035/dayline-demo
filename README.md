# Dayline

1日のタスクを時間軸で管理する、個人用の軽量デスクトップアプリ。タスクシュート・メソッドをベースに、見積もりと実績を記録して振り返る。データは各自のPCローカルに保存され、アカウント登録は不要です。

> このリポジトリは Dayline の**配布用**です（Webデモの公開とMac版の配布）。ソースコードは別リポジトリ（非公開）で管理しています。

## まず触ってみる（ブラウザ・インストール不要）

体験用のWebデモで、タスクの**作成・移動（ドラッグ）・編集・削除・開始/停止**をそのまま試せます。

**▶ https://kawaguchi1035.github.io/dayline-dist/**

- 変更は保存されません（ページを再読み込みすると初期状態に戻ります）
- 各自のブラウザ内だけで動くので、誰が触っても互いに影響しません

## データの保存について

- タスクのデータは**各自のPCのローカル（IndexedDB）にのみ保存**されます。クラウド同期はありません。
- バックアップや別PCへの移行は、設定画面の**エクスポート/インポート（JSON）**で行えます（※インポートは既存データを全置換します）。

## その他の機能・ショートカット

- アプリ内の右上 **?ボタン**（またはキーボードの `?` キー）で、**全ショートカット一覧**を確認できます。
- 主な操作：`Space` 開始/停止、`E` 編集、`R` ルーチン化、`U` 未完了に戻す、`↑/↓` 移動、タスクをクリックでフォーカス など。

## ダウンロード（Mac / Apple Silicon）

最新版のインストーラ（.dmg）は常にこのリンクから取得できます：

**▶ https://github.com/kawaguchi1035/dayline-dist/releases/latest/download/Dayline-macos-arm64.dmg**

### インストール手順
1. DMGを開き、`Dayline` を「アプリケーション」フォルダにドラッグ
2. 初回のみ、警告が出たら `Dayline` を右クリック →「開く」→「開く」（macOS 15以降は システム設定 → プライバシーとセキュリティ →「このまま開く」）
3. 「壊れているため開けません」と出る場合は、ターミナルで次を実行：
   ```
   xattr -dr com.apple.quarantine "/Applications/Dayline.app"
   ```

※ 未署名アプリのため、初回のみ上記の許可操作が必要です（無料配布のため）。対応環境は Apple Silicon（M1以降）の Mac です。
